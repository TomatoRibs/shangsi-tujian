# 上司图鉴

一份能离线打开的单文件网页，专治职场里那种说不清的憋屈。十道情境题，从四个维度给你的上级出一份鉴定报告，顺便算算你一年要为他多花多少个工作日。

## 怎么用

1. 直接用浏览器打开 `assets/shangsi-tujian.html`（双击即可，无需联网、无需服务器）。
2. 点选十道情境题，每题点完自动进入下一题。
3. 第十题之后会单独弹出一个窗口，给上级起个名（也可以跳过）。
4. 生成海报式鉴定报告，可一键存成图片直接发群，或用链接分享（链接只会还原你选的答案，不含任何个人信息）。

## 它量什么

- **四个维度**：控制倾向、担当指数、情绪平稳、决断速度。
- **八种原型**：显微镜型、甩锅风筝、摘桃侠、神隐菩萨、火山型、画饼仙人、变色龙、铁腕型。
- **血压指数**：把控制、低担当、低情绪平稳合并加权，给出绿 / 黄 / 红三档，并折算成「每周额外消耗小时数」和「一年折合工作日」。
- **他说·你回**：给出上级常挂嘴边的话、你心里想回的话，以及下次见面可以怎么回。
- **三年推演 + 保命清单**：长期走向与可落地的自我保护动作。

## 隐私

全部计算在浏览器本地完成，不联网、不上传任何数据。上级姓名只存在你本机的 `localStorage`；分享链接只编码你选的答案，不含姓名或任何个人信息。

## 免责声明

本工具是基于通用职场行为方法论设计的自评 / 自测玩具，**不是标准化心理量表**，未做信效度检验，也不做任何临床诊断。结果仅供娱乐与自我觉察，不构成任何职业或心理建议。
